# Security Policy

## Reporting a vulnerability

If you find a security problem in this project — for example an exposed secret, a
way to inject content into the site, or an issue in the automated translation
pipeline — please report it privately.

**Email:** hello@adamkolek.com

Please do **not** open a public GitHub issue for security reports.

Include as much detail as you can (steps to reproduce, the affected URL or file, and
the potential impact). I'll acknowledge your report as soon as I can and keep you
posted on the fix.

## Scope

This is a personal, non-commercial project, so there is no bug-bounty program — but
responsible disclosure is genuinely appreciated, and I'm happy to credit you if you'd
like. There is a single deployed version (the live site); there are no supported
release branches.

The obituary data comes from [bitcoindeaths.com](https://bitcoindeaths.com); issues
with the underlying data belong upstream.
